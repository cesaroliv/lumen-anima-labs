Privacy Policy

Last updated: September 22, 2026

This policy explains how Lumen Anima Labs handles information in connection with Marketplace Sync Guard and the lumenanima.com website.

Marketplace Sync Guard's purpose

Marketplace Sync Guard is a local-first, read-only browser extension for comparing inventory, price, SKU, presence, duplicate and status information across user-selected CSV and XLSX files. It does not automatically change marketplace listings, prices or inventory.

Operational data processed locally

Files selected for an audit, including catalog fields such as SKUs, prices, stock levels and statuses, are processed locally in the browser. Lumen Anima Labs does not receive those imported operational files or their audit contents.

The extension may store settings, mapping profiles, custom presets, price-tolerance settings and audit history on the user's device so that requested features work across sessions. Original imported files and raw file rows are not stored by the extension as part of audit history.

Pro licensing data

Free auditing does not require marketplace credentials or a Marketplace Sync Guard account. If a user chooses to activate or revalidate Pro access, the extension may request optional access to the Lumen Anima Labs licensing service.

For the current Hotmart purchase flow, the user may provide the Hotmart transaction code associated with the purchase. The licensing service sends that transaction code to Hotmart's API to verify the purchased product and transaction status. Hotmart may return purchase metadata as part of that verification response; the licensing service uses the minimum fields needed to determine entitlement and does not persist buyer profile data, payment-card data, imported marketplace files, SKUs, prices, stock levels, mappings or audit results.

After successful validation, the extension stores a signed Marketplace Sync Guard license token and minimum entitlement metadata locally on the user's device. The licensing service is designed without an application database for storing audit data or catalog data. Infrastructure providers may process ordinary technical request metadata as part of operating and securing their services.

Payments and delivery

Paid checkout and digital product delivery are handled by Hotmart, outside the extension. Marketplace Sync Guard and the Lumen Anima Labs licensing service do not collect or process payment card details. Hotmart handles payment, transaction and buyer-account information under its own terms and privacy practices.

Data sharing and Limited Use

Lumen Anima Labs does not sell user data, use extension data for personalized advertising, or build advertising profiles from Marketplace Sync Guard data. Data handled by the extension is used only to provide and support the extension's disclosed auditing and licensing functionality.

Marketplace Sync Guard's handling of user data is intended to comply with the Chrome Web Store User Data Policy, including its Limited Use requirements. User data is not transferred except where necessary to provide the requested licensing functionality, comply with applicable law, or protect the security and integrity of the service. Human access to user data is not part of normal operation and would occur only when necessary for security, support requested by the user, legal compliance, or with the user's explicit consent.

Retention and user control

Local extension data remains on the user's device until the user clears it or the browser removes the extension's stored data. Marketplace Sync Guard provides controls to clear audit history, clear Pro configuration and export supported local configuration or license data where those features apply.

The licensing service does not maintain a catalog-data or audit-history database. A transaction code submitted for validation is used to verify entitlement with Hotmart and is represented inside the signed local license token so later validations can confirm continued entitlement.

Website

The Lumen Anima Labs website does not require personal information for ordinary browsing and currently has no account system, advertising trackers or marketing cookies. GitHub Pages, which hosts and delivers the website, may process technical request information according to its own terms and policies.

Changes to this policy

This policy may be updated when Marketplace Sync Guard's data practices, licensing flow, payment provider or website functionality changes. Material changes will be reflected on this page with a revised update date.
