Mobile web QA checklist: responsive behavior, input and real-device risk

Responsive testing is more than shrinking the browser window. Use emulation for fast coverage, then remember that emulation is only an approximation of a real mobile device.

Fast browser pass

  • Test narrow and wide viewports; look for clipping, overflow and unreachable controls.
  • Check portrait and landscape layouts.
  • Verify tap targets, sticky headers, menus, dialogs and fixed-position elements.
  • Test forms with realistic text lengths and validation errors.
  • Check zoom and text resizing; important content should remain usable.

Performance and environment pass

  • Use Chrome DevTools device mode to approximate mobile viewport behavior.
  • Throttle network/CPU to expose loading and interaction problems.
  • Test offline/error states if the product promises resilience.
  • Remember: device emulation does not execute your code on an actual phone.
